# Contributing to Samadhaan Setu

Thank you for your interest in contributing to Samadhaan Setu! We welcome contributions from the community to help bridge the gap between citizens and local authorities.

## 🛠️ Development Environment

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yashcodesATgit/Samadhan-Setu.git
    cd Samadhan-Setu
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

## 📜 Coding Standards

-   Use **JavaScript** (ES6+) and **React 19**.
-   Follow the existing folder structure (`src/components`, `src/pages`, etc.).
-   Ensure all UI components are built using **Tailwind CSS v4** and **Radix UI**.
-   Maintain clear, concise comments for complex logic.

## 🚀 Pull Request Process

1.  Create a new branch for your feature or bugfix.
2.  Ensure your code builds and runs without errors.
3.  Submit a Pull Request with a clear description of the changes.
4.  Wait for review and address any feedback.
