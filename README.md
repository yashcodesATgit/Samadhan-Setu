# Samadhaan Setu

A high-fidelity, responsive civic engagement platform designed to bridge the gap between citizens and local authorities. This project is a modern, frontend-only prototype built with **React 19**, **Vite**, and **Tailwind CSS v4**.

## 🚀 Overview

Samadhaan Setu allows citizens to report local issues (potholes, lighting, sanitation) with location details and photos, while providing authorities with a streamlined dashboard to track and resolve these issues in real-time.

### Key Features
- **Modern Landing Page**: High-impact Hero section with full-viewport coverage and smooth Framer Motion animations.
- **Seamless Auth**: Integrated Login/Register modal system (Radix UI) for a friction-less user experience.
- **Citizen Dashboard**: Track personal reports and view live status updates.
- **Smart Reporting**: Dedicated interface for issue submission with category selection, priority leveling, and image upload simulation.
- **Admin Console**: Advanced filtering and status management system for authorities.
- **Full Responsiveness**: Optimized for all devices, from desktops to mobile phones, featuring a custom mobile navigation menu.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/)
- **State Management**: React Context API & `localStorage` (for prototype persistence)

## 🏁 Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/pages/` – SPA Route components (Home, Dashboard, Report, Admin)
- `src/components/` – Reusable UI components and layout helpers
- `src/context/` – Authentication state management
- `src/lib/` – Utility functions and storage logic
- `src/main.jsx` – Application entry point and router configuration
